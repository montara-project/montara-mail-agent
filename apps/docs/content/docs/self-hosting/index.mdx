The API and the web app ship as **one Docker image**: the Go server serves the API under `/api`, a health check at `/health`, MCP at `/mcp`, and the web app at `/`. All it needs beside it is PostgreSQL 18.

## Editions

The edition is fixed when the image is built.

| Edition | For | Notes |
| --- | --- | --- |
| `cloud` | A shared server, like the hosted app | Open sign-up. Needs [Resend](https://resend.com) (`FROM_ADDRESS`, `RESEND_API_KEY`) for verification emails. |
| `community` | One person on their own server | No sign-up: the only account is `SUPER_USER`, so `SEED_ON_BOOT=true` is required. No members and no billing screens. The web app talks to its own server until you [pick another](/self-hosting/reverse-proxy#using-another-server), which only this edition can do. |

Published images:

```text
ghcr.io/montara-project/montara-mail-agent/cloud
ghcr.io/montara-project/montara-mail-agent/community
```

Tags: `vX.Y.Z`, `vX.Y`, `latest`, and `sha-<commit>` for manual builds.

## What you need

- PostgreSQL 18 (the migrations use `uuidv7()`).
- A secret of at least 32 characters for `APP_SECRET`: `openssl rand -base64 32`.
- A model, if you want AI features: your own provider per organization, or a fallback `ANTHROPIC_API_KEY`. See [AI providers](/self-hosting/llm-providers).
- HTTPS in front of it for anything beyond your own machine. See [Reverse proxy and HTTPS](/self-hosting/reverse-proxy).
