## Signing in

- **Google.** The first sign-in creates your account.
- **Email and password.** A password account verifies its email before its first sign-in.

The API also offers password sign-up, magic links and password reset (see [Authentication](/api#authentication)); the web app does not show them yet.

## Two-factor sign-in

Under **Control Center › Security**, turn on an authenticator app: scan the code, save the backup codes, then confirm with a first code. From then on every sign-in, whichever method, asks for a code. A backup code works once in place of one.

## Password and sessions

Changing your password asks for the current one and signs you out everywhere. It also revokes your [API keys](/connect-mcp-clients). A password reset does the same.

## Privacy

- **Hide email addresses** (My Profile) masks addresses on screen in this browser, for screen sharing and recordings.
- **Timezone** (My Profile) sets the clock in the header and how dates read.
- Your email data is used only to provide the service and never sold.

## Choosing a server

Each browser talks to one server, the hosted one by default. Under **Control Center › Organization › Self hosted** (or **Change** on the sign-in page) point it at your own. See [Self-hosting](/self-hosting/reverse-proxy#using-the-hosted-web-app).
