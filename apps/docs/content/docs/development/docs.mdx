The docs are `apps/docs`, a [TanStack Start](https://tanstack.com/start) app built with [Fumadocs](https://fumadocs.dev). Every page is prerendered at build time, and the app runs as a Cloudflare Worker.

## Pages

- Pages are MDX files under `apps/docs/content/docs`. The file path is the URL: `self-hosting/docker.mdx` is `/self-hosting/docker`. There is no `/docs` prefix.
- Every page sets `title` (and usually `description`) in its frontmatter; the body starts at `##`.
- `meta.json` in a folder orders its pages and names the sidebar group. Never hand-write a route list.
- Link between pages with root paths, such as `/self-hosting/configuration`.

## Preview

```sh
pnpm --filter @montara-mail/docs dev          # http://localhost:3001
pnpm --filter @montara-mail/docs typecheck
pnpm --filter @montara-mail/docs build        # prerenders every page into apps/docs/.cloudflare/output
pnpm --filter @montara-mail/docs start        # serves that build in the Workers runtime
```

Search, `llms.txt` and `llms-full.txt` are generated at build time. A link to a page that doesn't exist fails the build. The Worker renders each page's Markdown copy and Open Graph image on request.

## Publish

The **Release** workflow builds the site and deploys it with `cf deploy` as the Worker described in `apps/docs/cloudflare.config.ts`, at `docs.montaramail.web.id`. Run the workflow by hand to publish a docs change without a release.
